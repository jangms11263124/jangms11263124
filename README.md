## Projects

### 싸스케 (SSASUKAE) — 실시간 화상 노래방

> SSAFY 15기 공통 프로젝트 **우수상** · 6인 팀 · 2026.07 – 2026.08

여러 명이 화상으로 만나 함께 부르고, 공격 카드로 서로를 방해하는 배틀을 즐기고, AI에게 가창 피드백을 받는 실시간 화상 노래방 서비스입니다.

**담당 · Frontend & AI 파트 기획**

- Web Audio API 기반 **보컬 오디오 엔진** 구현 — RNNoise(WASM) 노이즈 억제, SoundTouch AudioWorklet 실시간 템포·피치 시프트
- 카메라 **손 제스처 인식으로 음정·템포 DSP를 실시간 제어**하는 인터랙션 개발
- 수성전(카드 배틀) 발동 연출, 방 입장·진행 플로우, AI 피드백·마이페이지 화면 개발
- AI 파트 기획 및 프로젝트 최종 발표 자료 제작

### FinEdu — 사회초년생을 위한 금융 교육 플랫폼

> SSAFY 15기 관통 프로젝트 · 2인 팀 · 2026.06

경제·금융 입문 콘텐츠를 모아, AI가 사용자의 활동 기록을 분석해 맞춤 추천해 주는 금융 교육 서비스입니다.

**담당 · Frontend 중심 (2인 팀으로 백엔드 구현에도 참여)**

- Vue 3 + Pinia SPA 프론트엔드 전반을 담당하고, Django REST Framework 백엔드 구현에도 참여
- Gemini → GPT-4o-mini로 이어지는 **2단계 RAG 파이프라인**으로 사용자 맞춤 콘텐츠 추천
- JWT 인증, 커뮤니티(게시글·댓글·좋아요), AI가 매일 출제하는 오늘의 퀴즈, 카카오맵 기반 교육 행사 지도
